# Olá, me chamo Gabriel Oliveira Silva (`aka Back-byte`)

Sou desenvolvedor de software **Fullstack**, formado pelo curso Técnico em Desenvolvimento de Sistemas pelo **SENAI** e atualmente graduando-me em Análise e Desenvolvimento de Sistemas na **UCSal**. Minha trajetória é impulsionada pela curiosidade, aprendizado contínuo e pela busca constante por soluções bem estruturadas para problemas reais.

Atualmente atuo no desenvolvimento de sistemas corporativos, participando de projetos de alcance nacional e trabalhando com tecnologias voltadas para aplicações web modernas, integração de serviços e gerenciamento de dados. Tenho especial interesse por arquitetura de software, APIs, bancos de dados, boas práticas de desenvolvimento e construção de aplicações escaláveis.

Além da tecnologia, mantenho interesse em idiomas, escrita e comunicação, áreas que contribuem para minha capacidade de aprendizado e adaptação a novos desafios.
